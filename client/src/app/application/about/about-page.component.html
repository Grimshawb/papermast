The story behind Paper Mast

A calmer way to find your next great read.

Paper Mast is a full-stack portfolio project built around a simple idea: discovering books should feel as thoughtful and enjoyable as reading them.

The project

Your reading life, gathered in one place.

Paper Mast brings discovery and personal reading tools together. Explore a daily featured author, browse genres and bestseller lists, search for titles, and keep the books that matter to you on personal shelves.

Signed-in readers can organize what they want to read, what they are reading, and what they have finished—then set an annual goal and watch their progress grow.

How it works

From discovery to bookshelf.

  1. 1 travel_explore

    Discover

    Book data, bestseller lists, and author stories turn several trusted sources into one browsing experience.

  2. 2 bookmark_add

  3. 3 auto_stories

    Keep reading

    Move books through your reading journey and use a yearly goal to make progress visible.

Under the cover

Built as a complete product.

The Angular client is backed by an ASP.NET Core API, with MySQL for durable data and Redis for caching. The production application runs in containers behind Caddy, with automated builds and deployment safeguards.

  • Angular Interface
  • ASP.NET Core API
  • MySQL Data
  • Redis Cache
  • Docker + Caddy Delivery

Data sources

Made possible by open knowledge.

Paper Mast brings together book, bestseller, cover, and author information from these services. Each source remains the authority for its data.

  • menu_book Google Books API Book search, editions, descriptions, and publication details. north_east
  • format_list_numbered The New York Times Books API Current bestseller lists and rankings. north_east
  • person_search Wikipedia REST API Biographical context for the daily featured author. north_east
  • collections_bookmark Open Library API Genre discovery and cover artwork. north_east
